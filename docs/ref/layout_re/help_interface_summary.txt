Interface
Layout editor interface can be divided into 2 main parts
Menus and the toolbar, they
provide access to most commands and options. Below them there is an area
where you can see the windows of open layouts.
The layout windows, divided in an editing pane and a catalog pane.
The editing pane, is the area in which layouts
are actually showed and edited
The catalog pane, where you will see the
stock of shapes available in a specific layout.
An example of Layout editor interface.
The toolbar
Click on any item on this image to have help about it.
New
Creates a new layout file, you can have as many windows
open as needed.
Open
Opens an existing layout file.
Save
Saves your work
Beware! if you add or delete shapes other layouts related to the same session
will not be updated with the new quantities.
Cut/Copy and paste
Select the shapes you need to cut or copy, click on the
appropriate button and then click on paste.
Pasted shapes appear near the original ones, a bit offsetted on right and top.
Print
Prints the currently active layout. With "File/Print
setup" command you can set up some options about what is printed.
Show quality areas
You can decide to draw or hide quality areas, if they are
hidden you will see the material border and shape outline.
Fill quality areas
This option sets if quality areas are shown just in
outline or filled with the appropriate color.
Show shapes
Shows or hides all the shapes in your layout at once.
Fill shapes
Filled shapes are colored with standard colors or
accordingly quality areas, depending on the quality areas
settings. If this option is not activated you will see just shape outline or
outline and quality areas contours.
Let's see some examples of view/fill options.
Do not show quality areas, do not show shapes and do not fill quality
areas.
Shows unfilled quality areas
Show and fill quality areas.
Show shapes, do not fill shapes Quality areas.
Show and fill everything
Check overlay
If this option is turned on shapes that overlap each other
will be drawn with a squared pattern on them.
Overlapping might be caused by the use of nicking in the nesting
parameters, Layout editor cannot know if the overlapping comes from a legitimate
nicking or from a mistake, so always points out even the smallest overlapping.
This options requires a great deal of calculations, so we suggest to turn it
on only if actually needed.
In the middle of the layout two overlapped shapes, on the right one shape
of the same kind not overlapped
Full View
Instantly zooms the layout so that it can be fully seen on
the current window.
Resizing window might require an adjustment of zooming.
Zoom
Activates the zooming feature. The mouse pointer will
become a magnify lens and  you click anywhere in the layout you will have
that area magnified.
Another possible action is drawing a rectangle on the layout while in zoom
mode; Layout editor will try to maximize the zoom in the selected area.
Add shapes
Opens a dialog window that lets you select shapes from
your hard disk or from a network drive.
When you select a shape file you will see on the same window a preview of
that shape.
When you confirm your selections all the valid shapes will be made available
in the catalog.
Hint: You can drag shape files from Explorer to Layout editor to have the
same effect.
Edit position
Opens the "Edit
position" dialog
Bump control
Select one or more shapes and click one of these buttons
to start the bump.
The Edit pane
The edit area usually cover most of the layout window.
There you can see the material, the shapes on it and you can move,
rotate, bump,
flip them and so on.
Most operations can be done with your mouse or the corresponding menu
commands.
The Catalog
In the catalog you find a graphical list of the shapes available for the
layout.
See Working with Catalog for complete

In this section we will explain the less intuitive and more complex voices in

the material of the second layout will be ignored, just shapes will be
merged together.
Save as local
This command creates a folder that contains everything you
need to correctly load a layout, it is useful to move layouts from one
machine to another without bothering about the material and shape files
needed.
Load materials

scratch.

The Context menu
Context menu pops up when right - clicking on the layout.
Most of the commands on this menu acts on currently selected shapes, and are
disabled if no selection is available
Most of the context menu commands have the same effects of the corresponding
commands in main menu and will not be explained in this section, please see above.
Substitute
This command substitutes the selected shapes with the one
you select in the submenu. All the selected shapes will be modified, the
new ones will keep position, mirror and orientation of old
ones.
Advanced substitute
A more powerful version of the previous command, this one
pops up a dialog window that allow you to edit graphically the
substitution options.
The status bar
The status bar is the area at the bottom of Layout editor window, it shows
different information, depending by what is selected and by the mouse pointer
position.
Status bar look when mouse pointer is over an empty space in layout
Status bar look when mouse pointer is over a point in the material not
occupied by a shape
Status bar look when mouse pointer is over a point in the material occupied by a shape
In this case Shape means the shape under the mouse pointer.
Please keep in mind that every alteration you make adding, removing of
mirroring a shape might lead to schedule problems, please see the catalog
section for details.
When you manually edit a layout there is no automatic check about quality
areas.
While nesting routines are aware of quality areas constraints Layout editor
lets you see areas, but at the same time allows you to place anywhere a shape,
even outside the material if you whish.
Moreover constraints of any kind, for example rotation limits imposed to a
specific class of shapes are considered by nestings, but ignored by layout
editor.

Select a shape
Select a shape
To select one shape just click on it, remember that the
previously selected shapes will be unselected.
To unselect everything at once double click any empty area
in the layout window.
Another way to make a selection is the selection rectangle: click in an empty
area, then keeping the left mouse button pressed drag a rectangle, when you
release the button all the shapes completely contained inside the rectangle will
be selected.
Please note that only shapes that completely fit inside the rectangle are
selected.
Selected shapes can be identified because only the shape outline is visible.
Two selected shapes and one unselected one.
You can also selectively deselect shapes simply clicking an
already selected shape with shift key pressed.
A quick way to select everything is to draw a very big rectangle, surrounding
the entire layout and its surroundings.
To select More than one shape you can also click on all the
shapes you want to have selected with shift key pressed
Add and remove
To add a shape to the layout you can select it with a double
click from the catalog that you can find on the right side of the window, then
drag it to the layout and drop in the desired position.
If you start dragging a wrong shape press ESC key to abort the operation.
To remove one or more shapes just select them, then press
the DEL key or right click and select "delete".
Please note that when you add or delete a shape the number of reminders is
changed accordingly to what you are doing,
If the shape you need is not in the list of available shapes (called Catalog)
you have two ways to add it.
First of all remember that all the adding operations will modify the catalog
of the currently selected layout, so be sure to have the right one selected.
Method 1: use Windows
explorer to find the shapes you need, select them and drag the files
inside Layout editor, to complete the operation drop them.
Method 2: click on the "add shape" button on the
toolbar, then browse your disk to the right folder, select the shapes you
need and confirm.
Move and rotate shapes
Moving and rotating, as most operations, work on selected shapes only, so the
first thing to do is a selection.
Move shapes
to move a shape drag it around, then drop in the desired
place.
If multiple shapes are selected they will be moved together
Rotate shapes
To rotate a shape you have to right click it and then move the mouse around,
you will see the shape rotating in real time
If you own a wheel mouse you can use also the wheel to rotate selected shape,
as you would do with the right mouse click.
Special rotation options
When you are rotating multiple shapes at the
same time you can obtain those effects:
Simple rotate just select 2 or more shapes and rotate: each one
will rotate around its center.
Rotate as group if you keep the CTRL key pressed when
you are rotating all the shapes will be considered as a single one, rotating
around the center of an imaginary circle surrounding them.
If you use the "Set
rotation center option " you can place a small cross that will
define the rotation center of a shape or a group.
When a rotation center is set you can rotate as usual,
but if you keep SHIFT pressed while moving the mouse the selected
shapes will be considered as a group and rotated around the point you
stated.
It is up to your skill and wisdom to use all those features in an efficient
and productive way.
Search for overlapped shapes
If you wish you can do that, but a click on the
"Check overlay " button in toolbar is a faster and
smarter way: if shapes are overlapped they will be clearly marked in the layout.
Please note that if in your nesting parameters you activated the "Use
nicking " option some pieces are likely to be overlapped not
because of an error, but simply because they are nicked, e.g. you allowed a
small overlapping in low quality areas of your shapes.
Layout editor cannot handle this situation, so nicked shapes are marked as
overlapped, even if the overlap is allowed. It is up to you to recognize if the
solution can be accepted

Why not using the bump function?
Bump takes one or more pieces and tries to place them as close as possible to
already present pieces or to the material border.
How does it work?
First of all select one or more shapes
Click one of the black arrows with a yellow background that you can see in
the toolbar.
If you click the right arrow the selected shape will be moved right until it
collides with another shape or with the material border.
Remember that the shape will keep the same rotation they had at the
beginning, only position is altered.
To have a more precise control over the bump direction you
can activate bump with your mouse .
To do this
select one or more shape
double click one of them
keeping the mouse button pressed, move to the direction you wish to bump
them.
Another way to start a bump is keeping CTRL and SHIFT pressed
while you move your mouse.
If you use a 3 buttons mouse you can bump also using the
middle mouse button alone.
When bump operation begins you will notice that the pointer will become a
bow, and a line will start from the center of the shape you double-clicked
going to the pointer.
When you release the button the bump operation will be done.
Please remember that a bump on multiple shapes stops every
shape when one of them hits an obstacle on its path: they always move of the
same distance.
If no material is loaded bump operations are not possible.
How to fine tune the position of a shape
You can fine tune a shape position, click on the toolbar button with a big
plus with one or more shapes selected and a window will appear.
You will see a row of 3 boxes in which you can input numbers, another row of
3 boxes for numbers and small buttons with a plus and minus sign.
Let's see how it works.
If you change the values in the top row you
are setting the new coordinates or rotation , click on
"Apply abs" to see the changes in the layout.
If you put something in the bottom row,
say a 2 in the x box you will be able to use the plus/minus buttons:
clicking them the value you put in the second row will be added/subtracted from
the values in first row.
Clicking "Apply rel" has the same effect of clicking on the three
plus buttons, X, Y and rotation will be changed at the same time.
Please note that in this case with a click on plus or minus buttons the
change is immediately effective in the layout.
Can I change the allowed gap between shapes?
Have a look to "Tools/Change gap",
you will find the solution.
Please bear in mind that gap has an
influence on the check overlay functions: shapes not actually overlapped but
nearer than the allowed gap will be signaled as overlapped.
Can I change the cutting order
for the shapes in a layout?
Yes, it is possible, from the "Tools"
menu select "Cutting order".
The pointer will become a cross and each
shape will have a number inside or near it showing the cutting order.
If you click a shape you will reset its
cutting order to 0, going on clicking you will assign order 1, 2 and so on.
If you click a shape keeping CTRL pressed
you will preserve the previous order and the renumbering process will begin from
the fist shape you click.
For example a CTRL-click on shape
number 12 the order from 1 to 12 will be preserved, and the next clicked shape
will become the number 13.
In any case to abort the renumbering
process press ESC or select "Cutting order" from menu again to resume
normal operations.

Catalog
The
catalog shows the shapes available to compose a layout.
You can arrange its dimensions dragging the
splitter bar that divides it from the layout pane. If you need to rearrange
shapes in the catalog pane double click in an empty area.
What are the numbers
under the shapes in catalog?
The numbers are instances
of that shape placed in that layout and the number to be still placed.
More in detail: you see two couple
of numbers, in each couple the first indicates how
many copies of that shape have been placed in the layout you are looking at, the
second is the number of pieces to be placed.
Please note that the initial value of this information is the total stated for
the session you are nesting.
The
initial value of this information is the number of instances you requested for
that shape.
On the second layout of a session the
"to do " number is the total minus the ones placed in the first layout
and so on.
Of course when the to do number is 0 all instances of that shape needed to
complete a session have been placed, and when the placed and to do pieces are
equal it means that in that layout has been placed the last instance needed to
complete the stock.
The second couple of number
has an identical meaning, except that it refers to the mirrored stock of
shapes .
In "Leather goods" and "Job manager" you can state that you
want to cut both the basic shape and a mirrored one, for example if you produce
shoes it is a good idea to have left and right one produced in the same
quantity.
You do not have to draw both left and right,
just one, and then tell to nesting system how many normal and how many
"mirrored" shapes you need, the system will handle everything for you.
Advice about remainders calculation.
When you manually edit a layout the catalog for that layout will be correct,
but if it belongs to a calculated session the global session shape count will be
altered.
If you modify a layout in a session other layouts in the same session cannot
be aware of the changes, even if nesting is still in progress.
So if you insert, delete or mirror shapes be warned of potential problems
with your schedule.
Of course you can compensate your actions in different layouts, for example
if you delete a shape from a layout and you put it in another one belonging to
the same session everything will be all right.
If you are editing a layout that will be cut on multiple layers at the same
time please keep in mind that every alteration you make will be multiplied by
the number of layers.

in catalog
The right click menu in catalog offers some
interesting options:
Info

allows to change some parameters used by free nest strategy, it has no use if
free nest is not your nesting strategy.
Remove

the shape for viewing and editing in Shape Editor

What can I do with the catalog
The catalog has two main purposes
Show remainders Quantities for each shape
Provides a stock of shapes to be used to fill a material.
To get a shape from the catalog and use in the layout double click it and
drag its outline on your layout.
Click again to place it, of course you will be able to move it further later.

How to open a layout
You have five ways:
A double click on a .lay file
click the "View layout" instrument in the layout
window of "Leather goods"  or "Job manager"
open Layout editor, then use the file open command or the
open button on the toolbar
Drop a .Lay, or a .b file, it will be shown in the correct
way. You can even change the file extension and it will be recognized from
its actual contents.
Double click a layout viewer in Flashnest advanced or Job manager 2000, those applications provide a quick and "view only" layout preview
Can I print my layout?
Of course you can. You can click on the print
button on toolbar or select the Print
command in file menu to have your file printed with the current options.
To change the print setup, for example paper orientation use the "Print
setup" command in file menu.
You can configure:
standard paper and printer options
Custom layout settings, in details you can have the shape catalog printed or
not, and if it is printed you can force it to stay in a single page with the
layout, or to have the layout printed alone, and the catalog spread in as many
pages as needed.
I have a
session with many calculated layouts, do I have to load
them one by one?
Of course no.
If you are opening them from Job manager or
Leather goods you can select more then one layout before clicking on the button
to show them, they will be loaded at once.
An example of layout window from "Leather goods".
Another way is to open multiple layouts with
the "File/open" command, however the command "Open
next" in "File" menu can help you if you did not
open all the files you need, issuing this command the next layout will be loaded
automatically. Next layout means the one nested immediately after the active
layout, regardless of actual file order.
I need to merge two layout files, is it possible?
Yes, open the first layout, then form the
"File" menu select "Merge" and select the second layout.
Shapes will be merged, the material will be
the one of the first layout.

Layout files
Layout files: an overview.
The layout editor is the tool provided by Atom nesting system to see the
nesting results, eventually edit them or to build a new layout from scratch.
Layout files are identified with the extension ".lay".
At the end of each nesting a .lay file is saved.
If you are using "Job manager" or "Leather goods" to
browse your jobs you do not need to bother about the actual position of layouts:
simply you can watch them from the interface, so you do not need to search for
them.
Layout files: when and why
Layout files are created by the nesting strategies when a nesting is
completed
While a session is still nesting you can already see the layouts produced so
far.
A layout file contains a reference to the material used, references to the
shapes that contains and all the data needed to correctly place shapes
accordingly to the nesting results.
It can be used to see layouts before or after cutting and it is needed by the
cutting machine to have the data needed to cut.
Please note that only finished layouts are saved, if the nesting is working
on a layout it will be visible only when it is done.
Moreover
nesting does not go back on his steps: once a layout is saved it will not be
further modified, unless you rewind the session.
How to use them?
First of all to see the nesting results, so that you can
experiment different nesting parameters and analyze the results they produce.
In some cases you might want to manually edit the layout.
In this document you will be introduced to the main features of Layout editor
so that you can use it in an efficient way.
You will not need to read the fully document to find out the hint you need,
just go through the chapter titles to identify where is what you need.
Layout editor and other programs
Layout editor is supplied together with other programs that manage the whole
nesting system
The software can be divided in two main lines:
Flashnest base and advanced
Atom nesting system
In this manual this classification makes difference above all when we talk
about sessions, as Flashnest base and advance work without them.
You will see come icons to point out the differences, what is written in the
manual is valid for both lines, unless otherwise specified, although paragraphs
indicated with this icon  contain
information specific for Flash nest base and advanced, and this icon
is used to identify information specific for Atom Nesting system.
This manual refers to Atom Layout editor version 2.4.11,
released 4thth September 2000
